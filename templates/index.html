WELCOME TO YOUR LOCAL WORKSPACE

Ollama와 Local AI Lab 시작하기

이 콘솔은 내 PC에서 동작하는 Ollama 모델과 Flask Controller를 이해하고 점검하기 위한 로컬 전용 인터페이스입니다.

01

두 서버의 역할

Flask Controller는 브라우저 요청, 세션, 오류 형식을 관리합니다. Ollama는 실제 모델을 적재하고 AI 응답을 생성합니다.

02

콘솔 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 아래 명령을 실행합니다.

python app.py

브라우저: http://127.0.0.1:5000

03

Ollama 주요 명령어

ollama list
설치 모델 확인
ollama ps
현재 적재 모델 확인
ollama run qwen3.5:9b
모델 실행
ollama stop qwen3.5:9b
모델 적재 해제
ollama serve
Ollama 서버 시작
04

Thinking과 GPU 표시

현재 Controller는 Thinking OFF로 고정되어 있습니다. ON/OFF 옵션은 후속 단계에서 제어할 수 있습니다.

ollama ps의 100% GPU는 모델이 GPU에 전부 배치됐다는 뜻이며, GPU가 항상 100% 사용 중이라는 의미는 아닙니다.

05

콘솔 사용법

  1. C에서 Health Check를 실행합니다.
  2. D를 Unlock한 뒤 메시지를 입력하고 Enter로 전송합니다. Shift+Enter는 줄바꿈입니다.
  3. E에서 대화를 확인하고 Session List와 Reset Session으로 현재 세션을 관리합니다.
  4. F에서 API 상태와 응답 성능을 확인합니다.

Reset은 확인 후 현재 세션의 대화만 초기화합니다. D의 + New Chat으로 만든 세션 번호는 유지됩니다.
